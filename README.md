# 솔향치과

제공된 레퍼런스의 섹션 흐름을 토대로 독립적으로 작성한 치과 사이트입니다. 레퍼런스의 코드·사진·문구·사업장 정보를 가져오지 않았으며, 건강니 치과 이미지도 사용하지 않았습니다. 솔향치과용 이미지 여덟 장을 새로 생성했습니다.

## 실행

Node.js 24 이상이 필요합니다. 외부 런타임 패키지 없이 실행합니다.

```powershell
npm ci
npm run dev
```

주소: http://127.0.0.1:5185

```powershell
npm test
npm run build
npm start
```

`npm start`는 `dist/`의 프런트와 서버 API를 함께 제공합니다. 포트는 `PORT`, 바인딩 주소는 `HOST`로 변경할 수 있습니다.

## 화면 구조

브랜드 비주얼, 편안한 진료 소개, 진료과목, 집중 진료, 진료팀, 진료 철학, 선택의 이유, 자연치아 보존, 가이드 임플란트, 진정치료 상담, 소아진료, 고객센터 순서입니다.

상단 메뉴는 `#doctor`, `#guide`, `#specialist`, `#treatments`, `#child`, `#contact`로 이동합니다. 우측 빠른 메뉴와 하단 상담 폼은 화면에 고정되며 모바일에서는 메뉴·상담 버튼으로 바뀝니다. 장식 순번과 화살표 버튼은 없습니다.

## 실제 구현된 기능

- SQLite에 저장되는 예약·상담 접수
- 진료별 상담 시간, 한국 시간 기준 영업시간, 점심·휴진일·지난 시간·90일 초과 예약 차단
- 예약 접수번호와 이름·휴대폰 번호를 모두 확인한 조회
- 일정 변경, 취소, 캘린더 ICS 다운로드
- 트랜잭션 기반 중복 시간 방지와 중복 제출 멱등성
- 진료 상세·FAQ·개인정보 안내·모바일 메뉴·주소 복사
- 상담 신청 성공·오류·로딩 상태

문자·메일 발송과 네이버·카카오 예약 연동은 포함하지 않습니다. 접수번호는 예약 완료 화면에서 확인하고 보관해야 합니다. 이름과 연락처만으로 다른 사람의 예약을 조회할 수는 없습니다.

## 데이터와 보안

`.local/solhyang.db`에 데이터를 저장하며, `.local/storage.key`로 이름·연락처·예약 접수번호를 AES-256-GCM 암호화합니다. 조회용 접수번호·이름·전화번호는 HMAC으로 색인합니다. 두 파일은 Git과 웹 공개 경로에서 제외됩니다.

서버에서 입력·동의·요청 출처·요청 크기를 검증하며 POST API는 IP당 분당 100회로 제한합니다. SQL에는 바인딩된 매개변수를 사용합니다. 예약 생성·변경은 트랜잭션 내에서 겹치는 시간을 확인합니다.

로컬 운영자가 접수 내역을 확인하려면 `npm run inbox`를 사용합니다. 이 명령은 연락처를 복호화해 터미널에 표시하므로 접근 권한이 있는 운영자만 실행해야 합니다. 공개 관리자 API는 없습니다.

## 배포

서버와 쓰기 가능한 영구 디스크가 있는 Node.js 호스팅이 필요합니다. **GitHub Pages만으로 예약·상담 API를 실행할 수 없습니다.**

1. Node.js 24 환경에서 `npm ci`와 `npm run build`를 실행합니다.
2. `.local/`에 영구 볼륨을 연결하고 접근 권한을 제한합니다. DB와 키는 반드시 함께 백업합니다. 키를 잃으면 연락처를 복구할 수 없습니다.
3. `HOST=0.0.0.0`, 플랫폼의 `PORT`, `APP_ORIGIN=https://실제도메인`을 설정합니다.
4. `npm start`를 실행하고 HTTPS 리버스 프록시를 연결합니다.
5. 주소·전화·사업장 정보, 개인정보 보관 기간과 삭제 절차, 실제 진료 정보 등을 운영 주체의 정보로 확정합니다.

현재 사업장 정보는 입력 예시이며, 생성된 이미지와 의료진 일러스트는 실제 의료진·시설의 증빙이 아닙니다. 실제 의료기관으로 운영하기 전 진료 정보·정책 검토와 운영 설정이 필요합니다.

## 코드 구조

- `web/`: 새로 작성한 화면·예약 컨트롤러·스타일
- `shared/catalog.mjs`: 진료 항목 및 공통 정보
- `server/`: HTTP API, 시간 정책, SQLite 저장, 암호화
- `scripts/`: 빌드와 로컬 운영자 접수 조회
- `tests/`: 서버 API·시간 정책·지속성·보안 검증
- `assets/`: 솔향치과용 고유 생성 이미지와 SVG 파비콘

GitHub Actions에서 테스트·빌드·의존성 검사를 수행합니다. 공개 서버 배포는 별도 설정입니다.
